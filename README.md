# Ethereal Wedding Invitation Studio

Aplikasi web statis interaktif yang dirancang untuk membuat undangan pernikahan digital bernuansa *ethereal* dan elegan. Proyek ini dibangun menggunakan teknologi web murni tanpa menggunakan *framework* tambahan, dengan pemisahan struktur file agar lebih mudah dikelola secara manual.

## Latar Belakang Masalah
Banyak pasangan calon pengantin yang ingin membagikan undangan pernikahan secara digital dengan tampilan yang estetis dan interaktif. Namun, seringkali platform yang tersedia bersifat kaku, berbayar, atau kurang fleksibel untuk dikustomisasi sendiri. Proyek ini dibuat sebagai solusi mandiri (*self-hosted*) yang ringan, cepat, dan kodenya dapat diubah secara bebas.

## Teknologi yang Digunakan
Seluruh proses penulisan kode, perancangan tata letak, dan pengujian dilakukan secara mandiri menggunakan **Visual Studio Code (VS Code)**:
* **HTML5**: Menyusun struktur semantik halaman utama dan panel formulir editor.
* **CSS3**: Mengatur gaya visual, efek *glassmorphism*, tipografi klasik, serta tata letak responsif.
* **JavaScript (Vanilla JS)**: Menangani logika interaktif dinamis seperti pengisian formulir, hitung mundur (*countdown*), pemutar musik latar, dan pembentukan tautan khusus tamu.
* **Platform Penyimpanan**: Kode yang selesai diketik di VS Code disalin dan diunggah langsung (*upload file*) secara berkala ke repositori **GitHub**.
