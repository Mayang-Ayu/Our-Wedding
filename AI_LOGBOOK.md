# Ethereal Wedding Invitation Project

Dokumentasi ini disusun untuk memenuhi ketentuan pencatatan pemanfaatan Kecerdasan Artifisial (AI) secara terbatas dan proporsional. Seluruh proses perancangan, penulisan kode di Visual Studio Code (VS Code), pengujian lokal, hingga penyalinan file (*copy-paste/upload*) ke repositori GitHub dilakukan secara mandiri.

## Tahapan Catatan Pemanfaatan AI

### Tahap 1: Eksplorasi Ide & Perancangan Solusi
* **Pemanfaatan AI**: Meminta referensi awal mengenai gaya estetika antarmuka web undangan pernikahan berkesan lembut dan elegan (*ethereal*).
* **Validasi & Modifikasi Mandiri**: 
  * Konsep dari AI hanya diambil sebagai gambaran umum. Seluruh pemilihan palet warna, struktur formulir input (*builder*), serta pengaturan hierarki direktori file dikerjakan dan dirancang sendiri secara manual di VS Code tanpa ketergantungan pada AI.

### Tahap 2: Penyusunan Kerangka Kode (Scaffolding)
* **Pemanfaatan AI**: Meminta contoh sintaks dasar untuk perhitungan waktu mundur (*countdown timer*).
* **Validasi & Modifikasi Mandiri**:
  * Kerangka kode dari AI dimodifikasi secara total agar terintegrasi dengan elemen formulir yang dibuat sendiri. Seluruh kode CSS untuk efek *glassmorphism*, tata letak grid responsif, dan pemisahan fungsi modular JavaScript diketik, diuji, dan disesuaikan langsung di editor VS Code.

### Tahap 3: Pemecahan Masalah & Penanganan Galat (Debugging)
* **Pemanfaatan AI**: Berkonsultasi mengenai penanganan parameter URL (`URLSearchParams`) untuk menampilkan nama tamu undangan secara dinamis di halaman sampul.
* **Validasi & Modifikasi Mandiri**:
  * Solusi yang diberikan AI diuji coba dan diperbaiki langsung di VS Code. Saya menyesuaikan logika pengondisiannya agar program tetap stabil dan tidak mengalami error meskipun parameter nama tamu tidak disertakan oleh pengguna.

### Tahap 4: Refleksi & Penjelasan Kode
* **Pemahaman Pengembang**: 
  * Seluruh baris kode di dalam berkas proyek ini sepenuhnya dipahami dan dikuasai. Pengerjaan murni mengandalkan kemampuan pemrograman mandiri menggunakan VS Code (melalui ekstensi *Live Server*), di mana hasil akhirnya disalin secara manual ke repositori GitHub.
